# Green Normalized Difference Vegetation Index (GNDVI)

Calculates GNDVI for chlorophyll concentration estimation.

## Usage

``` r
d4h_gndvi(nir, green)
```

## Arguments

- nir:

  SpatRaster. Near-infrared band.

- green:

  SpatRaster. Green band.

## Value

A SpatRaster containing GNDVI values.
